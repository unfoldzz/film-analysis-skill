# 电影分析 Skill

把一部电影做成可对照原片阅读的中文导演课：**全片导读 → 原片顺序逐镜报告 → 独立收官影评**。

这个仓库只提供流程、证据规范与交付清单，不附影片、截图、字幕或个案课程包。Skill 不提供自动看片、字幕翻译或剪辑程序；分析深度取决于实际可用、可合法处理的片源及客户端工具。

- [SKILL.md](SKILL.md)：工作流程与核心约束
- [逐镜与交付](references/shot-and-delivery.md)：切点、证据、图解和文件检查
- [资料与收官](references/sources-and-finale.md)：官方资料、影评分歧和关键戏的选择

## 使用

将整个 `film-analysis-skill` 目录放入你的客户端支持的 Skill 目录，保留 `SKILL.md` 和 `references/` 的相对路径。也可以直接把 `SKILL.md` 和两个参考文件交给支持阅读本地文档的助手。先提供片名、版本、可访问片源，视需要补充字幕和交付范围。授权仅分析一个片段时，不声称对整部影片已有完整观看结论。

示例请求：请用电影分析 Skill 做全片导演课。先发 00 导读，再按原片顺序交付，最后依据前面全部证据独立重写收官。
