# 逐镜记录与交付

## 工作记录

先记录项目的片源版本、起止时间、字幕版本与校准点、交付权限和范围。记录叙事主体、片尾附加内容及其边界。每个范围保存如下字段；内部可存原始切点数据，但面向读者仅用时间码。

| 项目 | 内容 |
| --- | --- |
| 片源与段落 | 版本标识、包序号、段名、原片起止时码、相邻关系 |
| 镜头证据 | 真实切点；动作前、动作中和结果的时码；对照图或图解及说明 |
| 技法及作用 | 屏幕边界、视线、调度、声音或剪接如何分配信息；观众何时知道什么 |
| 内容与联系 | 人物选择、后果、和全片的具体关联；至少保留有意义的另一种理解 |
| 状态 | 已核实、仍需核实、不适用；生成、验收、送达状态分开记录 |

自动切点检测只作候选。回看片段复核硬切、叠化、闪回、手机或监控画面、暗场、噪点和短插镜。原声可用时按相邻时间复聆；只有字幕时写“字幕提示”，不可当混音证据。来源不支持的具体技术参数写未知。遇到无法解码或缺字幕，说明对哪些结论有影响，不补造连续画面和台词。

## 全片关系图与叙事位置

工作表字段：人物和正在争取的事｜前一处选择与时间｜本段动作与可见后果｜当场可知｜后段兑现或反证与时间｜看完全片才有的重读。阶段推进时核对反复动作、物件、声响和权力关系有没有改变；没有足够证据就不强拉主题。短过场写清信息、情绪、路线或视点从哪里交到哪里。

## 一页写法

- 一组互补截图配短时码，再写一段推理，不把单图当作一段连续动作的证明。
- 当示意图确有信息增益，画俯视位置、移动方向、景别变化或声画接点。仅据画面重建的部分标示为推断，不显示未知的精确机位。
- 普通镜头完整覆盖，正文密度按叙事作用分配。关键组在图旁连接前后两场的具体动作，至少比较一种有意义的替代拍法，说明对观众所知或情绪节奏的影响。必要时分行记声入、切画与可辨认声源。
- 验收：只读这一包能知道全片中的位置；换成另一场，同一段论证不能原样成立。结局和后见必须清楚标识。两种读法都有证据时留出分歧，不把它们压成导演意图。

## 交付检查

先将本包的切点清单、镜内行动清单与引用图证对应。检查开头、后半部与结尾执行同一覆盖标准。发现后半部同等复杂却只有少量图证时，回看片源补事件、动作或声画接点，不用等量增页填齐。跨包证据可在分析中引用邻段时码；剪辑文件不因此重复收录。

1. 逐包核对顺序、覆盖、重叠是否刻意，以及切点和图注。视频摘录须匹配文档边界；预先对齐中文，保留原声，必要时硬嵌；无法可靠对位就标明。静态报告仍可先行，但标注此包视频未交付。
2. PDF 核查分页、中文和图文不截断；Word 渲染确认标题、图表和分页，显式设东亚字体并避免模板回退到日文字体。PDF、Word 使用同一标题基名，内容一致。
3. ZIP 实际解压后检验文件、目录深度和校验值。对中间包解压后离线打开 MP4，抽查片头、片尾及字幕同步；核对同包 PDF 与 Word 同标题，时间范围与视频一致。各包序号补零，长段可用明确子编号，包数取决于片子。总目录索引到每个普通文件夹及原片范围。不在总包里套独立 ZIP。
4. 阶段保存证据、生成状态和经过确认的交付记录。中断后从首个未验证的包恢复；不把上传成功或包已生成说成用户验收。超出附件限制时保留已验总包并说明状态，不擅自改用公开分享。
