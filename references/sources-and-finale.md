# 资料与全片收官

## 用资料找漏看的戏

| 资料 | 能支持什么 | 不能替代什么 |
| --- | --- | --- |
| 完整片源和声音 | 镜头顺序、可见动作、声画关系 | 对人物内心与主创意图的全知 |
| 官方影片页或影展档案 | 作品、版本、发行、片长、署名 | 观看记录 |
| 主创一手陈述 | 创作出发点、工法、表演意图 | 某镜的唯一含义 |
| 历史原始记录 | 真实事件、制度背景 | 将虚构情节认成当事人事实 |
| 专业影评与观众长评 | 选择关键场面、指出分歧、提供反证 | 票数、共识或对原片的核看 |

记录作者、标题、出处、可打开的原链和所读范围。优先追到署名原刊；聚合平台上的摘录与普通观众意见各自标记。无法访问的页面列为缺口，不能写成已读；若同样意见出现在多处，去重。不要凑平台数、信完读不到的摘要或抄评论。

## 两轮资料检索

- **广搜**：用片名、原名、导演和发行语境找独立署名影评；片子在哪种语境被讨论，就补查相应语种和媒体。可从专业刊物、本地评论、影展、观众长评和聚合索引进入，可沿 Letterboxd、豆瓣、Rotten Tomatoes、IMDb 与 Metacritic 逐站核查：用户要求五站时逐一记录读到什么，但名单不是全文配额，也不是可靠性的排序。
- **场景搜**：用地点、动作、道具、台词关键词、形式特征及原文异写找不同观点，尤其查询初稿解释不了或漏掉的场面。追到原刊并阅读论点所在前后文。不同文章转述同一采访仍只有同一主创原话。
- **登记实际读取**：全文／可访问段落／摘要或搜索摘录／仅条目／打不开。可核段落只承担其直接支持的有限说法；只有摘录的条目是线索，不据此概括整篇观点。遇付费墙、删文或语言障碍，换可访问的独立来源，再说明缺口怎样限制对读。不以影评数、评分或影片简介补空。
- **归因层级**：“创作者在某次访谈说”是制作陈述；“评论者认为”是读法；“原片在此处切接、动作顺序如此”是可回看的证据。“这一处理可让观众……”是分析，不等于断定意图。看似冲突时保留各层，不让访谈为每个镜头定案。

## 关键戏雷达与验收

初看和分包时各扫一次：列下不可逆的选择或主动撤退、话与行动反差、少对白的身体行动、空间或视点易手、突出的声画实验、前后呼应、评论分歧和主论点的反例。一条只需 `场景与原片时间范围｜为什么关键｜人物与形式的转折｜归入的逐镜包｜收官去向`。全片完整观看不可用时，标成暂定候选，不能把缺段勾成覆盖。不要按戏剧强度、台词密度或易截图程度筛掉关键戏。

收官起稿从问题和证据重新写，不拼接旧报告。选入的关键戏至少复看**进入、变化、退出**，必要时加相邻帧、声入/声源、及跨场对照。先核谁在什么位置、谁先移动、谁何时能看见谁；再分镜内动作、取景改变或物理剪切。若场面出现屏幕或录制设备，另核画面边界、可辨操作者与主影片机位；不能凭画面相似认定素材来源。截图选最少足够的安全原片证据，必要时用不暴露私密细节的远景、环境帧或注明性质的示意图，重要身体行动仍应写清。

写争议时用同一场景逐项比较：**观点 A 与依据 → 观点 B 与依据 → 原片动作／视点／声轨核对 → 支持与不能推出的结论**。没有可靠异议就写替代读法及其局限，不冒作外部观点。若评论称段落太慢，核对究竟延迟了什么、谁何时能解释，以及延迟只重复了什么；允许两种判断针对不同局部同时成立。

导出前把高优先候选与最终 PDF/Word 的节标题、时码和图证映射；未选列原因，仍未核实列缺口，不能拿一张图、包编号或总索引当细读通过。选段全片有前中后分布但不要求均分。若后来发现应入选而漏写，复看上下文、增补正文与必要图证，再复查目录、两种文档和包内索引，而非只在聊天补一句。发布技能仅保留通用文本和可公开发布的示例；不带原片、截图、字幕、私人链接、访问标识、内部工作笔记或实际个案交付物。发布行为另按用户授权执行。
