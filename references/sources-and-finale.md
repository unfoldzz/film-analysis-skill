# 资料与全片收官

## 用资料找漏看的戏

| 资料 | 能支持什么 | 不能替代什么 |
| --- | --- | --- |
| 完整片源和声音 | 镜头顺序、可见动作、声画关系 | 对人物内心与主创意图的全知 |
| 官方影片页或影展档案 | 作品、版本、发行、片长、署名 | 观看记录 |
| 主创一手陈述 | 创作出发点、工法、表演意图 | 某镜的唯一含义 |
| 历史原始记录 | 真实事件、制度背景 | 将虚构情节认成当事人事实 |
| 专业影评与观众长评 | 选择关键场面、指出分歧、提供反证 | 票数、共识或对原片的核看 |

记录作者、标题、出处、可打开的原链和所读范围。优先追到署名原刊；聚合平台上的摘录与普通观众意见各自标记。无法访问的页面列为缺口，不能写成已读；若同样意见出现在多处，去重。不要凑平台数、信完读不到的摘要或抄评论。

## 收官工作顺序

1. 不看旧收官当底稿。用已核镜头包、全片叙事和观看笔记重新问：开头让观众以为什么？后来哪一场迫使我们改判？
2. 先列场景候选再排序。优先人物不可逆的选择、说法与动作不一致的场面、前后同一物件或姿态变了用法、不同影评人对同一拍法的争议。不要让“最政治”“最激烈”或最漂亮的单图等同重要。
3. 每个核心场景给一组带时间的原片图证：动作发生前后的位置、一次剪切或声画变化、可以被另一种解释挑战的地方。回到电影具体指出该段在全片结构中挪动了哪条线，而非把主题外加上去。
4. 写独立论点，再覆盖宏观结构、主题、人物行动、表演与拍法的关键关系。说明影片最有力量和最薄弱之处。结尾带回导读的重点，但不把所有歧义锁成唯一答案。

例：如果评论认为“段落太慢”，先比较被延迟的信息和后来谁能解释这件事；若延迟改变了理解，指出准确的切接，若只是确认同一处差距，也如实写。两种判断可以在同一部电影里同时成立。
