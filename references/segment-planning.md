# 通用分包规划

## 先划戏，再定包数

1. 建一个全片场景表，记录动作目标、阻碍、人物或视点的接手、信息揭露、局部结果以及候选原片时码。有闪回、交叉剪辑或片中片时同时标出叙事层，不把每次换时空都算一场新戏。
2. 为每包写一个能由原片回答的问题，如“谁从旁观改为介入，影片何时让我们看出来？”选结尾时优先放在动作结出后、下一件事启动前；核对前后画面和音轨或字幕，不把仍在起作用的反应、肖像等落点切到下包。声桥未关时在两包里注明其连续，不为了追求干净切口挪动时码。
3. 拆得太碎时先找相邻的同一行动：同一谈判的提议与回应、同一目标的前后对照、同一交叉剪辑的多方。通常用包内章节解决，别把小节另存成 ZIP。保留独立短包的理由是它完成一件独立的事，合并会模糊结构；保留较长包的理由是切开会破坏一件事怎样发展。
4. 列出首尾包含关系、章标题和新旧编号映射，检查是否有缺口、重叠或只有视频没有分析的区段。按全片时长、戏剧结构和分析密度估算总包数，不为凑时长、页数或包数改动切点。全片确有片头、字幕页、献词、署名或外部附录时，标明它们属于哪个结构层，不与表演段用同一密度。
5. 正文从新包的问题出发重新组织。旧截图、时码与可验证的小段观察可以复用；旧包导语和总结不能代替新论证。发现镜头误读、密度失衡或前后关系被切断时，回到原片补证、重写相关段，必要时整包重写。

## 同一覆盖标准，不要求同一密度

- 逐包记真实切点和每个足以改变理解的镜内动作或声画变化。日常短过场可短写；信息密集的长镜需要更多取证时间；重复画面不重复讲同一结论。看似重要刺激的音响须注明听审、字幕或未核实，不能凭画面补声。
- 同一场里的短插镜、人物沉默的反应、跨镜声响、离画和再入画、视点与片中摄影机归属要核对。有新增证据才说明旧稿哪里遗漏，不把多几句话算成补完。
- 区分戏剧单元和传输限制。优先保持文稿、图证和源时码不变，评价剪辑压缩后字幕和动作是否仍清楚；若一个逻辑上完整的包不能在当前渠道交付，说明限制，再选择获授权的私有交付方式。不要为了附件大小切断关键动作，也不要擅自公开发布。
- 首包、转折处与后半部各抽检一段，对照真实切点、分析正文、画面、字幕和 ZIP 内剪辑边界；抽检不是正文覆盖的替代。一旦改包边界，更新交付目录与收官证据索引，保留原片时码，不暗改已确认的影评论点。
